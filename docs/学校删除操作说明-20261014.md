# 学校删除操作说明

管理员登录后，进入“学校报名”，点击要处理的学校。学校详情右上角有“删除学校”，和“返回学校列表”并列。

1. 点击“删除学校”，页面会读取后台最新学校档案。
2. 核对学校名称、所属组别、已保存人员和三人赛项目名单数量。有尚未提交的输入时，确认框会说明这些修改将一并放弃。
3. 点“取消”、按 Escape 或关闭确认框，会保留当前输入。默认焦点在“取消”。
4. 点“确认删除”，成功后返回当前赛事学校名单，数量同步更新。

删除会移除该校档案及其人员、项目名单。已有三人赛或个人赛参赛报名记录的学校不能删除，后台会显示原因并保留学校和当前输入。学校列表显示“0 位人员”也需要核对报名引用。

拒绝删除时，页面会按真实原因给出可执行步骤：①已有比赛成绩或名次——先由管理员/编排对相关场次正式更正或取消，或在成绩页删除/作废相关名次；②赛程或编排方案已锁定——由管理员撤回阶段确认或解锁；③仅有报名登记——先在学校报名中退出或删除报名记录。确认报名名单为空后再删除学校。

编排与成绩人员不显示删除入口；记录员和查看者保持原有访问范围。所有非管理员调用删除接口也会被拒绝。

正在提交报名、报名提交结果待核实，或报名已保存但最新正式名单尚未读取时，删除暂时不可用。先按页面提示完成报名核对，再处理学校。

如果出现“删除结果尚未确认”，点“核对删除结果”。这个操作只读取当前赛事学校名单：学校已不在名单时返回列表；学校仍在时保留输入，允许重新核对并明确确认删除。核对失败时保持提示，继续尝试核对即可。

更新后先保存当前工作，再刷新正在使用的网页。若旧页面资源仍未更新，可用 Ctrl+F5 强制刷新。无需新依赖或数据库迁移。本次验证使用独立测试库，不操作真实赛事中的学校。
