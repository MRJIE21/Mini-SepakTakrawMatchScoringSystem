# 学校报名页边界修复（1.3.19）

浏览器缓存 stss-shell-v80。先保存当前输入，再刷新页面加载新版；无需数据库迁移或新增依赖。

- 新增人员改名后，重新核对当前同名人员；确认不同人并填写区分信息后可继续。
- 局域网 HTTP 下可生成报名标识；浏览器随机能力不可用时显示原因并保留输入。
- 未知提交始终使用原内容重试，确认成功后恢复正常编辑；下一笔明确拒绝的提交可修改。
- 只填号码、区分信息或主动改性别也会保留新增输入。退出项目后，未添加输入仍可补全或清空。
- 移除新增人员会清理非活跃项目中相关引用；活跃参赛和冻结阵容仍需先核对。
- 导入遇到后台变化后，可在同一弹窗重新核对；旧核对结果不能覆盖新草稿，表格文本保留。
- 个人赛已有选手时就地新增只加入学校名单，换人须明确选择。
- 保存成功后返回项目报名和最新统计；读取失败会明确显示已保存，点击读取最新正式名单即可重试读取，不必再提交。

本轮不改变比赛规则、后端同名校验和请求幂等协议；测试数据与实际赛事隔离。HTTP 场景由本机浏览器非可信域名验证，不能视为完成实际手机/平板网络测试。

经用户补充批准，修复安全转义姓名的模板回导兼容性：例如 `=甲` 下载后为 `'=甲`，回导会复用已有人员；同时存在两种姓名时要求填写人员 ID。保留 CSV 安全转义，不对未知人员的姓名自动去掉前缀。已运行的后台需要重新加载代码才能启用这项后端修复。
