# 三人赛比赛规则设置

从侧边栏“赛事管理 → 三人赛规则设置”进入，直接设置当前赛事的一套规则。所有组别、男子及女子三人赛共用，以后新增项目自动继承；不同赛事分别保存，个人赛不受影响。尚未添加三人赛项目时也可以先设置规则。常用规则可直接点击选择；“自定义参数”或“查看和调整详细参数”可设置全部参数。编排、记录和查看角色可以查看已保存规则，只有管理员能修改。

原“赛事设置”页面内的规则入口已移除。赛事资料、组别项目和场地仍在“赛事设置”维护。规则页取消组别、项目选择；切换顶栏赛事后显示所选赛事规则，地址仅保留当前赛事。切换赛事或离开页面前需确认放弃未保存输入，保存或结果待核对时先完成当前操作。

旧数据中各三人赛项目规则相同时，升级直接迁移为赛事统一规则。存在差异时页面显示“旧规则尚未统一”，可展开原有规则差异；下方表单是尚未应用的统一草稿。管理员明确确认保存后，全部未开始场次及以后新增项目采用统一规则。在确认前，原比赛继续使用各项目原规则；已开始、已有计分或提交、已完成比赛始终保留原规则快照与成绩。即使采用默认草稿，也需要首次保存确认统一。

选择一局一胜、三局两胜、五局三胜，或自定义 1、3、5、7、9 局制。系统自动计算所需胜局数，一方先赢过半局即结束。

普通局可选择常用规则后继续修改，也可直接自定义：

- **直接获胜**：先到目标分且领先即可获胜。默认是目标 15 分、15 分封顶，15:14 结束。
- **领先两分获胜**：达到目标且领先两分才结束。可关闭封顶或设置封顶分；例如目标 15、17 封顶，15:14 继续、16:14 结束，17:16 按封顶结束。
- **平分后固定加赛**：到“目标分减 1”平后改为先到固定加赛分。例如目标 15、加赛 17，14:14 后 16:14 仍继续，先到 17 才结束。该示例参考[加拿大藤球协会三人赛规则](https://www.sepaktakraw.ca/regu-sepak-takraw)，具体以本赛事规程为准。

目标分为 2—99 的整数，封顶分最大 999 且不能小于目标分，固定加赛分最大 999 且必须大于目标分。不封顶时系统不会在 999 分自动判胜。

决胜局默认沿用普通局。取消“决胜局沿用普通局”后可单独设置；三局制对应第 3 局，五局制对应第 5 局，一局制的唯一一局使用决胜局设置。

点击“保存规则”会先显示原规则、新规则及全赛事适用场次数量，核对后再确认保存。规则修改仅用于未开始的比赛。比赛领取记录后，系统固定该场规则，之后转交、恢复、更正和打印都沿用该规则。原有默认比赛与旧草稿兼容三局两胜、15 分封顶。

如果确认期间另一设备领取比赛、修改规则或变更组别项目，保存会要求重新核对；本次输入保留。保存结果尚未确认时，先点击“重新读取状态”核对，系统不会自动重复保存。更正局分必须符合原比赛规则，不能填入本应早已结束后继续产生的比分。

升级前先保存或导出当前输入，再重启后端服务并刷新浏览器。本轮升级保留 `原库文件名.before-event-team-rules-v2.db` 备份；之前的 `原库文件名.before-team-rules-v1.db` 也会保留。备份无效或规则异常会报错，需要先核对。旧页面逐项目保存接口会提示刷新，避免把单项目修改意外扩大到赛事。升级不清空赛事数据，较长局制的记录表按 A4 横向打印。
