# 自动编排赛程

从项目工作台的“赛程”点击“自动编排”。先在“分组”确认学校分组，并在赛程建立、核对需要使用的阶段。

1. 选择本次编排的已确认阶段。小组赛将补齐单循环，淘汰赛和名次赛使用已有来源及决位规则。来源小组赛尚未完整时须一并选中。
2. 设置预计单场时长和同队最短休息分钟数，均须大于0。休息从上一场预计结束计算，换场地也遵守。例如09:00开赛、预计30分钟、休息30分钟，下一场最早10:00开始。
3. 勾选可用场地，填写一个或多个起止时间段。午休可设置09:00—12:00与13:00—17:00两段。安排会避让同赛事已有场地占用。
4. 默认保留已有场地、时间并补齐缺项。要重排请选择对应模式和阶段；已领取、已记录或有成绩比赛保持，原比赛编号不变。
5. 生成预览，核对阶段、对阵、场地、预计起止、休息和新增/保留/重排状态。排不完时增加场地或时段、缩小阶段范围后重新生成，不会自动减少休息。
6. 全部安排完成后确认保存。预览10分钟有效；期间分组、场地或比赛状态变化须重新预览。保存结果不确定时，在原赛程页“核实并重试原操作”，不要重复新建。

编排按预计时长生成计划。实际比赛延误后，可人工调整后续时间或重排未开始场次；人工调整仍校验场地、休息、前序和已保存的可用时段。旧比赛未标时长时，预览会说明本次估计。已保护比赛缺少时间而无法核对同队休息时，需要先完善该场比赛时间。

分阶段编排时，每场比赛保留自己的时段和休息规则。后来编排淘汰赛不会覆盖先前小组赛的规则；提高最短休息后，即使现有位置无需移动，也会在确认时保存更严格的休息要求。

单次相关比赛上限2000场，待排上限500场，最多1000个场地窗口；搜索5秒或10万次展开到限时报告未排完，可分阶段处理，不承诺最短赛程。此有界搜索保持约束，未找到方案不等同于已证明无解。

管理员、赛事组织者沿用原权限操作；记录员和查看者不增加编排权限。规则单独存储，不改变计分规则或已确认成绩。
