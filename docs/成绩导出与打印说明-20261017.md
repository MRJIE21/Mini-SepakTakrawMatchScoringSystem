# 成绩导出与打印说明（1.3.15）

本说明对应当前版本的报表导出；所有导出只读取当前赛事数据，不修改成绩。

## 可用导出

| 入口 | 内容 | 格式 |
| --- | --- | --- |
| 成绩页 / 更正与导出 | 单个项目的成绩（三人赛逐场比分与结果，个人赛成绩、状态、名次、积分） | CSV、XLSX、打印成绩单/名次表 |
| 成绩页（小组排名区） | 当前小组排名（积分、C 值、Z 值、说明） | CSV、XLSX |
| 学校总分页 | 当前大组别学校团体总分与分项目明细 | CSV、XLSX、打印总分表 |
| 更正与导出 | 整届或单个项目赛程 | CSV |
| 更正与导出 / 记录台 | 单场记录表：已结束场次带局分与结果，未开始为空白表 | 打印 HTML、CSV |
| 编排页 | 小组抽签分组表 | 打印 HTML |

按钮只对管理员/编排显示；记录台的记录表记录员也可以打印。后端导出接口要求登录且具备该赛事访问权限。

## 打印页稳定地址

- 学校总分与项目成绩的“打印”按钮改为打开 `/print.html?type=category-notice|school-notice&...`：地址可复制、可刷新，刷新后按当前数据重新渲染；
- URL 只带业务参数，不含登录令牌；打印页从同源 localStorage 取登录令牌并用 Authorization 头请求导出接口，权限仍由原接口校验；
- 未登录、无权限、数据不存在或网络失败时，打印页显示对应提示与返回入口，不会停在空白页；
- 把打印地址复制到其它浏览器或隐私模式时需先登录该账号。记录表等其它打印入口保持原方式。

## 正序/倒序

- 成绩页（项目成绩、小组排名）、学校总分页、更正与导出页的导出区域有“排序：正序/倒序”下拉，默认正序。
- 正序保持原有行顺序；倒序把当前行顺序整体反转（名次类从末名到第 1 名，逐场成绩从最后一场到第一场）。
- 打印页的倒序只作用于已确认名次/成绩块；待确认行固定追加在最后并显示“待确认名次（不计入）”分组行。
- 只影响顺序：行内容、列、行数、名次/积分/待确认统计和页码不变；CSV、XLSX、打印页使用同一方向。
- 切换项目/分组或刷新页面后恢复正序；赛程 CSV、记录表 HTML/CSV、抽签分组表不受排序影响。

## 状态与口径

- 赛程 CSV 的“状态/结果状态”、成绩 CSV 的“结果状态”、记录表 CSV 的“胜方/结果状态”均为中文，例如“已确认、正常完成、主队、客队胜（主队弃权）”。
- 个人赛 `未参加/未完成/取消成绩` 是最终状态：不参与名次、不计积分，名次显示“—”，学校总分不再把它们列为“待确认项目”。真正缺成绩或尚未确认名次时仍显示“待确认”。
- 个人赛成绩单页头“待确认 N 人”与表格中的待确认行数使用同一口径。
- 个人赛有效次数、失误/违规次数按整数显示；空值保持空白。
- 学校总分 CSV 的最后一列是“待确认项目”，原有列顺序不变。
- 组别内没有任何已开赛场次时，学校总分榜、CSV、XLSX 与打印公告的名次列显示“未开赛/无成绩”或“—”，不再按学校名称生成第 1、2 名；已开赛但全 0 分的组别仍按规则排名。

## XLSX 说明

- 项目成绩、小组排名、学校总分提供 `.xlsx`，与对应 CSV 同源同列；表头加粗、首行冻结、列宽按内容估算。
- 文本按文本写入（不会当作公式执行）；数值（名次、积分、次数等）写为数值单元格。
- 使用 Python 标准库生成，不需要安装 Office 或额外软件包；用 Excel、WPS 或 LibreOffice 打开即可。

## 记录表

- 已结束且有逐局比分：打印页自动填入各局主客得分、局分、结果勾选和结果状态，可用于赛后留档。
- 已结束但没有逐局比分（主队弃权、客队弃权、未完成、取消）：结果勾选和中文结果状态照常显示，页脚注明“本场无逐局比分（弃权/未完成/取消），结果以系统记录为准”。
- 未开始且无任何结果：仍是空白记录表，供现场手工记录。
- 局列按该场冻结的规则生成；五局及以上保持 A4 横向打印。

## 升级提示

版本 1.3.15、缓存 `stss-shell-v76`。完成或保存当前输入后刷新页面即可加载新版打印/导出行为；无需重启后端。导出失败时页面会明确提示，不会产生半截文件。
