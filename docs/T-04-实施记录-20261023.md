## 2 设计决定

- 抬头只呈现既有数据，不新增接口字段；规则快照仍取领取时固定的 `draft.rules`，继续只读。
- 状态徽标复用既有 `DRAFT_STATUS` 词表（等待手动开局 / 记录中 / 已结束待核对 / 提交中 / 失败待重试 / 已提交 / 已接收待独立复核），不新增状态名。
- 底部操作条只在移动端出现，且只做“查看赛后核对”的定位，不复制提交按钮，避免两处提交条件不一致。
- 保存状态与比分从 `draw()` 同一处更新，保证与计分区一致；保存失败时文字转红并保留“未保存”语义。
- 未改动 `scoring.js`（计分函数）、`submit.js`（提交包）、`store.js`（本机存储与版本栅栏）。
