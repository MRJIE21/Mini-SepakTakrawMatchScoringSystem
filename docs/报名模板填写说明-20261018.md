# 学校报名表模板填写说明（1.3.18 · 2026-10-18）

版本 1.3.18、浏览器缓存 `stss-shell-v79`；本轮只改模板与填写指引，导入规则不变、无数据迁移。

报名页“粘贴 / 导入学校报名表”提供三个下载：**报名模板（8 列）**、**填写说明**、**示例 CSV**。
模板为 UTF-8 CSV（带 BOM），可直接用 Excel 打开；保存时请保持 CSV 格式与表头。

## 一、默认 8 列

| 列名 | 填写规则 | 示例 |
| --- | --- | --- |
| 项目 | 本组别项目名称；“仅建人员”时留空；同一项目每名队员一行 | 男子三人赛 |
| 参赛选择 | 参加 / 不参加 / 退出 / 尚未决定；留空等同参加 | 参加 |
| 运动员 | 三人赛每名队员一行（3—6 行）；个人赛一人；仅建人员必填 | 张三 |
| 性别 | 男 / 女；留空时按项目性别 | 男 |
| 常用号码 | 1—20 的整数，可留空 | 7 |
| 项目号码 | 1—20 的整数；仅三人赛填写 | 7 |
| 队长 | 只有一名队员填“是” | 是 |
| 种子序号 | 三人赛可填一次正整数；个人赛不填 | 5 |

旧 14 列模板（含学校、项目ID、运动员ID、同名新建确认、区分信息等）仍然兼容；可选列说明：

| 列名 | 填写规则 |
| --- | --- |
| 学校 | 可选；省略时按当前工作台学校导入 |
| 项目ID | 可选；项目名称不唯一时使用 |
| 运动员ID | 已有人员需要精确匹配时填写 |
| 同名新建确认 | 确认新增另一位同名人员时填“是” |
| 区分信息 | 同名人员必填，用于区分不同人 |
| 报名备注 | 可选；写入项目报名备注 |

## 二、填写示例

```csv
项目,参赛选择,运动员,性别,常用号码,项目号码,队长,种子序号
男子三人赛,参加,张三,男,7,7,是,5
男子三人赛,参加,李四,男,8,8,,
男子三人赛,参加,王五,男,9,9,,
男子个人赛,参加,赵六,男,11,,,
女子三人赛,不参加,,,,,,
女子个人赛,尚未决定,,,,,,
```

- 三人赛每名队员一行，每行重复项目与参赛选择；种子只填一次。
- 个人赛每校限报 1 人，只填运动员、性别、常用号码。
- 不参加 / 尚未决定行不填人员字段。
- 只建人员不报名：项目与参赛选择留空，填写运动员、性别、常用号码。

## 三、常见错误

1. 三人赛只写一行 → 只会登记 1 名队员，请按实际人数增加行。
2. 个人赛填了项目号码或队长 → 请改填常用号码、留空项目号码与队长。
3. 同一项目多行填了不同种子 → 整批拒绝，请只保留一个种子。
4. 未替换示例姓名就导入 → 会建立“示例…”人员，请先改成真实姓名。
5. 号码超出 1—20、队长重复、同一项目队员重复 → 整批拒绝并提示行号。

填好后在报名页导入弹窗中“核对表格”，预览通过并应用到报名表后，再预览整批变更并提交。
