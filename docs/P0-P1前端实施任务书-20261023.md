## 1 总览

### 1.1 目标

把已评审通过的设计交付物1—7 转成前端可直接认领、可直接验收的任务包，明确每单的页面编号、组件、状态、验收门、估时、依赖、非目标与交付物，使 P0 页面先上线、P1 页面按链补齐，全程不改变既有业务规则、权限边界、复核机制、数据冻结与审计要求。

### 1.2 实施原则

- 页面与组件只做设计与实现对齐，不新增业务能力、不调整计分与排名算法。
- 菜单与入口按角色呈现，但权限仍以后台校验为准；未授权直达必须出现说明页，不得静默跳转。
- 复核页面不提供任何直接改分入口；大屏编辑内容不得自动上屏；危险操作必须影响范围、原因、二次确认与审计回执齐备。
- 状态名称统一使用中文固定词表，不出现“已提交即正式”“直播即最终”等表达。
- 先令牌与外壳、后页面；先 P0 执行链、后 P1 赛前链与输出链；每阶段设门禁，未通过不得进入下一阶段。

### 1.3 任务范围

本任务书覆盖 9 张任务单：T-03 赛事首页与工作台壳、T-04 现场记录台、T-05 成绩复核工作台、T-06 更正与导出打印、T-07 大屏控制与展示、T-08 报名工作台、T-09 抽签与赛程编排、T-10 排名积分与导出收尾、T-11 账号权限与审计；另引用前置任务 T-01 令牌与基础组件、T-02 外壳与导航，以及收尾任务 T-12 响应式与可访问性回归。

## 附录 B 术语表

| 术语 | 含义 |
| --- | --- |
| 候选 | 已提交但未独立复核确认的结果，界面统一显示“待独立复核” |
| 正式成绩 | 经独立复核确认后的结果，进入排名与输出 |
| 更正 | 对已确认成绩的修改，须生成候选并再次复核 |
| 退回 | 复核人将候选退回作者补正，需填写原因 |

| 领取 | 记录员取得场次记录任务，任务归属唯一 |
| 转交 | 管理员或成绩人员带原因把任务改派，保留交接记录 |
| 直播 | 记录台的实时比分快照，不参与正式排名 |
| 推送 | 把控制台编辑内容显式发布到大屏的动作 |
| 配对码 | 大屏设备与控制台建立只读凭据的六位码 |
| 轮空 | 对阵中确实没有对手的位置，与“待定来源”不同 |
| 待定来源 | 后续场次的参赛方尚未产生，显示来源说明 |
