# 赛事设置操作说明（2026-10-13）

进入“赛事设置”后，先看顶部概况，再按“赛事资料 → 组别与项目 → 比赛场地”的顺序设置。点击顶部入口会定位到对应区域，当前输入继续保留。各区域单独保存。

## 查看和修改

赛事资料默认显示已保存的名称、日期和比赛地点。点击“修改资料”填写，完成后点“保存赛事资料”。日期和地点可以后补。“比赛地点”填写体育馆等场馆名称；馆内 1 号场、2 号场在“比赛场地”中添加。

先选择组别，再查看该组的项目。各组分别报名、比赛和排名，例如“实验赛 → 甲组 → 男子三人赛”。项目卡片显示名称、性别、类型和实际报名数量；三人赛按队，个人赛按人。

点击“修改名称”才会展开名称输入、保存、取消及删除。取消会恢复已保存名称。已有参赛名单或比赛的项目仍受后台删除限制。点击“进入项目工作台”进入当前组的对应项目，继续维护报名、编排和比赛。

## 添加项目和场地

点击“添加项目”，选择男子三人赛、女子三人赛、男子个人赛或女子个人赛。名称自动生成，也可自行修改。切换组合会更新自动名称，并保留自己填写的名称。先核对所属组别和预览，再点“确认添加项目”。选择和预览不会创建项目。

当前组已有的组合显示“已添加”，不能重复开设。其他组可以独立开设相同组合。

新建赛事向导第 3 步同样使用这套常用组合：每个组别可点“一键添加常用四项”，一次生成男子三人赛、女子三人赛、男子个人赛、女子个人赛；已存在的组合不会重复添加，生成后仍可逐项改名、删除或继续手工添加。

场地全赛事共用，可以后补。点击“添加场地”，填写如“体育馆 1 号场”，再点“确认添加场地”。默认排在已有场地后面；需要调整时展开“手动设置顺序（可选）”。具体比赛的时间和场地在项目工作台安排。删除场地前会说明影响：已安排在该场地的比赛改为未安排，比赛本身保留。

## 理解保存状态

| 状态 | 处理方式 |
| --- | --- |
| 有未保存的修改 | 输入尚未提交，完成后点击本区域保存。 |
| 正在保存 | 等待结果，保存按钮暂时不可重复点击。 |
| 已保存 | 后台已确认本次提交。其他区域的输入继续保留。 |
| 已保存，列表待同步 | 写入已完成，点击“重新读取状态”同步列表。此操作不会重复新增。 |
| 保存结果尚未确认 | 先点击“重新读取状态”核对后台。未找到提交结果时，原输入保留，可核对后再次明确提交。 |
| 字段错误或保存被拒绝 | 根据提示修改，原输入保留。 |

切换组别或取消时，如涉及未保存输入，会先询问是否放弃。刷新页面读取后台已保存数据；未提交输入不作为浏览器草稿恢复。

## 使用更新

产品没有新增运行依赖，也不需要数据库迁移。沿用现有启动方式和访问地址。服务正在运行时，刷新网页取得更新；如仍显示旧样式，可在已保存输入后强制刷新。未启动时使用产品目录中的 `start.cmd`，以启动窗口给出的实际地址为准。

管理员可编辑赛事结构；编排与成绩人员可查看只读设置。记录员和成绩查看者保持原有页面权限。新建赛事继续使用五步向导，最终确认后才创建赛事。
