# 赛事设置视觉优化

根据合页后的实际截图，调整页头过高、宽屏表单拉伸、卡片留白和操作层次。

参考 GitHub 项目源代码中的布局原则：

- [Ant Design Pro 基本设置](https://github.com/ant-design/ant-design-pro/blob/master/src/pages/account/settings/components/base.tsx) 与 [表单样式](https://github.com/ant-design/ant-design-pro/blob/master/src/pages/account/settings/components/index.style.ts)：垂直表单、按字段长度选择宽度，并限制编辑区宽度。
- [Seerr 设置页](https://github.com/seerr-team/seerr/blob/develop/src/components/Settings/SettingsServices.tsx)：限制内容最大宽度，使用响应式网格。
- [AnythingLLM 设置页](https://github.com/Mintplex-Labs/anything-llm/blob/master/frontend/src/pages/GeneralSettings/AudioPreference/stt.jsx)：分别组织标题、说明和有宽度上限的设置控件。

保留原蓝白风格，自行调整本系统的页面结构和样式，不引入新依赖。

## 调整内容

- 设置页内容居中并限定最大宽度，减少超宽屏中的空洞和过长输入框。
- 页头保留标题、当前赛事和页内定位，去除重复的结构说明条和大面积卡片背景。
- 赛事名称和地点使用完整行，开始与结束日期并排，表单阅读顺序更自然。
- 收紧场地空态，减少重复说明，分清列表和新增区域。
- 项目名称输入限宽，操作区域统一对齐；性别和类型使用轻文本，报名数量保留状态标记。
- 减弱常驻删除按钮的视觉重量，保留原有确认与权限逻辑。
- 页内导航顺序与区域的实际排列一致；手机依次显示三个区域。

三个设置仍在同一页面；各处独立保存、输入保留和刷新读取后台的规则继续保留。本轮没有数据库迁移或业务数据写入。

## 验证结果

- 专项浏览器回归通过：保留原有同页保存、输入保留、切组、后台刷新、权限、向导、报名种子和记录队列检查；补充页头高度、超宽居中及空场地布局核对。
- 已核对 2539、1365、768、390、320 像素宽度的截图；无场地状态另核对四种宽度及桌面首屏。最后调整按钮对齐和标题焦点范围后，专项回归再次通过。
- 全局 135 个页面与尺寸组合检查通过，无脚本错误或整页横向溢出；6 项前端静态检查通过。
- 实际 2 个数据库、66 张表内容与本轮修改前的只读快照一致。运行中的服务已提供 `stss-shell-v41` 和更新后的界面文件，刷新页面即可使用。
