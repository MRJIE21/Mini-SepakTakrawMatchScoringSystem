# 学校报名工作台

从侧边栏打开“项目工作台”，有报名权限的账号直接进入“报名名单”，显示当前组别的学校；点击学校后，在同一工作台整理报名。录入员和查看员继续进入各自允许的比赛或成绩页签。旧学校链接仍会转入对应学校。

通过顶部“大组别”和“比赛项目”下拉直接切换，无需先选择进入方式。工作台恢复当前赛事的合法最近项目，没有记忆或原项目已失效时使用可用的默认位置。“报名名单”始终使用同一个学校报名页面，学校内可设置本组别多个项目。明确的概况、赛程和成绩链接继续进入对应页签。有未提交修改时先确认是否离开，取消会保留原输入和选择。

学校内保留三个页签：

- 人员名单：维护学校全部人员，保留稳定档案 ID；同名人员需要核对区分信息。
- 项目报名：设置本组别全部项目的参加、不参加或退出，维护队员、项目号码、队长、种子和备注。顶部当前项目用于工作台定位，学校内可同时调整多个项目。
- 核对与提交：先预览整批变更，确认后人员与项目一次保存。未修改项目保持原状。

粘贴或上传本校多项目报名表后，先核对、应用到报名表，再预览整批提交。没有项目时仍可先新增学校、整理人员；没有组别时先配置组别。

切换学校、组别、项目或离开工作台时，未提交修改会提示确认。取消切换会保留原输入和选择。正在提交时先等待结果；提交结果不明时使用“核实并重试原提交”，保留原提交标识，避免重复生效。

“返回学校列表”回到当前组别与项目。新建学校默认当前组别，明确选另一组后会进入目标组工作台。管理员可在详情删除未被报名引用的学校；确认前读取最新档案，结果不明时先核对删除结果。

本次更新没有新增运行依赖或报名数据迁移。保存当前输入后，按原方式启动 `start.cmd` 并刷新浏览器；必要时使用 Ctrl+F5 更新页面资源。
