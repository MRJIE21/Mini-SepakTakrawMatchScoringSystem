# 发布说明（P0/P1 前端改进版 1.5.0，G5）

日期：2026-10-23
适用：藤球比赛计分系统 P0/P1 前端实施（T-03—T-11）+ G5 回归修复
版本：`1.5.0`（package.json / README / CHANGELOG / 使用说明 / release-manifest 已同步；外壳缓存 `stss-shell-v92`）

## 1 本版主要变化

| 区域 | 变化 |
| --- | --- |
| 首页与壳 | 赛事首页改为指标卡+待办聚合+项目卡；页头/面包屑/上下文条统一；四态（加载/空/错误/无权限）齐备 |

| 成绩复核 | 候选/正式/差异三联对照；退回必填原因；记录员只读“我的提交”；无改分入口 |

| 账号与审计 | 账号页搜索/角色/状态筛选；我的账号（改密、退出所有设备、显示设置）；高对比主题 |
| G5 修复 | ①旧链接 `#/catalog` 从“静默回首页”改为跳转项目工作台报名名单；②徽标与次要文字对比度提升到 WCAG AA；③首页标题层级 h1→h2→h3；④删除无入口的 `enrollmentImport.js`；⑤外壳缓存 v82→v92 |

## 2 发布前检查（必须）

1. `web/sw.js` 的 `CACHE` 已是 **`stss-shell-v92`**；任何发布都必须递增该版本，否则已安装客户端不会更新外壳；
2. `release-manifest.json` 已用 `tools/build_release_manifest.py` 按 1.5.0 重算（348 个文件，旧清单哈希记入 `previous_release_manifest_sha256`）；发布流水线仍应执行 `python tools/build_release_manifest.py --check`，并在提供 `src/source_manifest.json` 的环境复核源码快照哈希；
3. 版本号已同步：`package.json`、`README.md` 首行、`CHANGELOG.md`、`docs/体育馆大屏使用说明-*.md`、`docs/报名模板填写说明-*.md` 均为 1.5.0 / `stss-shell-v92`；
4. 发布前执行一次备份：`python run.py backup`，并 `python run.py verify --input <备份目录>`；
5. 停服后再替换文件（恢复/升级期间不要运行服务实例）。

## 3 升级步骤

1. 备份并校验（见上）；
2. 停止服务（确认业务端口无监听；`stss.instance.lock` 文件可能保留，下一次启动会自动检测失效 PID 并接管，无需人工删除）；
3. 覆盖安装新版本文件；
4. 启动服务，管理员登录；
5. 冒烟：首页指标、工作台报名、记录台打开一场（不提交）、成绩复核列表、导出与打印页、审计日志、账号页；
6. 回归记录见 [G5回归记录-20261023.md](G5回归记录-20261023.md)；
7. 通知现场：首次打开新版本后浏览器会更新离线缓存，建议提前联网打开一次。

## 4 回滚

- 停止服务，用升级前备份执行 `python run.py restore --input <备份目录> --yes`；
- 恢复保护：若升级后新增了复核事实/权限状态，旧备份会被安全拒绝（“禁止回退独立复核账号/权限真源”），此时应前向修复而不是强行覆盖；
- 前端回滚需同时回退 `sw.js` 缓存版本（保持与旧包一致），否则浏览器仍使用新外壳。
