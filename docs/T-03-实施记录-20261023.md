## 2 主要设计决定

- 首页页头统一为“面包屑 + 唯一 H1 + 状态徽标 + 主操作”，与交付物3 P1、L-01 一致；全页只有一个 H1。
- 赛事级四指标从既有 `/api/events/{id}/dashboard` 数据计算，未新增接口：参赛主体、已确认/总场次、待独立复核、可记录场次；有目标页的指标可点击直达。
- 待办聚合使用接口已有的 `candidates_pending`、`disputes_open`、`placements_confirmed/required`、`matches_ready`，不改变任何状态口径。
- 项目卡保留“按实际数据推荐下一步”，个人赛不出现编排入口；新增待复核与争议角标。
- 最近确认场次的结果列改为中文并带状态色，正式口径仍以独立复核确认后的结果为准。
- 工作台页签改为吸顶横向滚动（移动端），当前页签自动居中；上下文条补“三人赛/个人赛、只读、报名与种子已冻结”徽标。
- 待记录场次支持“全部 / 未领取 / 我已领取”筛选，仅前端过滤，不改变领取归属规则。
- `sw.js` 缓存版本 `v81 → v82`，使已安装页面能取到新的 CSS/JS。
