# 分组与赛程（1.2.0）

在项目工作台选定组别和三人赛项目，进入“分组与赛程”。

1. **分组管理**：设置学校分组名额，完成抽签并确认。建立小组赛阶段，核对后由管理员确认。这里只确定小组成员。
2. **比赛赛程**：点击“新增比赛”，选择阶段、小组和双方学校，按组委会安排填写轮次、场地和时间。编辑表单按需打开。
3. **比赛记录**：领取任务、计分并提交；在“成绩与名次”核对并确认小组排名，后续来源才解析成实际学校。
4. **设置后续赛程**：选择淘汰赛或名次赛，保存后核对全部对阵。管理员确认才创建正式场次，可在小组赛结束前先确认待定来源的赛程。

“淘汰及评次图”还会列出“自定义比赛”阶段的逐场补赛/弃权记录（轮次、双方、比分、状态）；该阶段没有场次时显示“暂无自定义比赛”。

淘汰赛包含全部小组的前两名。两组为A1对B1、A2对B2；四组为A1对B1、C1对D1、A2对B2、C2对D2，更多小组按此延续。后轮相邻场胜者推进，最后分别进行冠亚军赛和三四名赛。

名次赛选择各组第三名或第四名，首轮仍按相邻组同名次对阵。范围由组织者设置：两组可填写5—6或7—8名；四组可将第三名安排为5—8或9—12名，也可分A/B与C/D两个阶段，各自填写不重叠的范围。范围学校数须与参赛来源一致，不占用主淘汰赛1—4名，不超过本项目有效学校数。

非完整签位会在预览中列出轮空位置，须明确勾选确认。未确认小组排名、前场未结束或成绩依据失效均属于待定，不会自动当成轮空。

每场使用固定M编号，并显示参赛来源和胜负去向。轮次、时间、状态和场地筛选只改变排列；筛选后没有结果时显示“清除筛选”，点击可恢复完整列表。调整场地时间使用独立版本，其他人的修改不会被盲目覆盖。

管理员可填写原因撤回阶段确认；未开始的场次将移除。已有领取、计分、成绩或其他阶段依赖时，系统会阻止撤回。已有成绩使用正式更正流程，人工名次不会被比赛推导结果覆盖。

出现“操作结果待核实”时，使用“核实并重试原操作”。原请求不可改成另一份内容，刷新后仍可核实；核实前不能继续新的赛程写入。普通未保存表单仍使用原有离页保护。

原自动辅助编排已删除。旧编辑链接显示退役提示，旧专属写接口返回410。历史赛程和成绩可读取、更正；不会通过旧接口重新生成比赛。本次升级保留账号与密码，并增量更新数据库结构。
