# D08 移动导航与结构树重构（2026-10-24）

## 1. 承接与验收标准

- **D08 来源**：2026-10-23 走查与 2026-10-24 产品确认 D08「允许下一版本调整基线」；本批将 390 导航从横排滚动改为“分组抽屉 + 底部快捷栏”，并按 `docs/baseline/README.md` 的冻结规则新建 `baseline-20261024.json`，不覆盖 `baseline-20261023.json`。
- **结构树目标**：按 2026-10-23 方案 §5.2/§5.3 落实可独立交付的部分：
  1. 侧栏按任务域分组，新增“学校报名 / 分组与抽签 / 赛程与场地 / 成绩与名次”一级入口；
  2. 工作台页签从 8 个收敛为 5 个：概况 / 报名 / 赛程（含分组与抽签子视图） / 比赛 / 成绩；个人赛为概况 / 报名 / 成绩录入 / 成绩；
  3. 成绩复核从工作台重复页签收敛到侧栏唯一入口；更正与导出、成绩复核归入“成绩”组；
  4. 旧 `tab=tasks/groups/review`、旧隐藏路由与 `#/review` 保留兼容；
  5. 不改变角色权限矩阵、复核模型、排名口径与 G0 令牌。

**验收标准（本批执行口径）**：
- ≤620px：顶栏出现“菜单”按钮；侧栏成为保留分组树的抽屉，关闭态不占布局高度；底部 4 个快捷入口；打开后焦点进入抽屉、遮罩可见、Escape 关闭、页面无横向溢出。
- ≥621px：保持桌面侧栏（1440）或横排导航（834），不显示移动按钮/底栏。
- 结构树：侧栏分组与入口文案、工作台页签数量/顺序、旧参数兼容、viewer 只读边界均与上述目标一致。
- 回归：42+ 个浏览器套件、Python 全量、静态测试全绿；三端页面级 `overflowX ≤ 0`。

**保守假设/待确认**（不自行扩展需求）：
- “成绩与名次”入口指向既有 `#/results`（默认第一个项目），未新增项目选择器；
- “赛程与场地”仍复用项目工作台赛程页，不拆分独立页面；
- 更正与导出暂未拆出“审计与备份”独立页（方案 §5.3 IA-05 的后半部分），因涉及 admin 页签路由与权限验收，留待独立批次；
- 移动端底部快捷入口按角色给 3 个链接 + “更多”；未新增“我的任务”聚合页。

## 2. 结构树前后对照

### 2.1 调整前（2026-10-23 走查时）

```text
侧栏（6 组 / 管理员 10 个入口）
├─ 赛事管理：赛事首页、赛事设置
├─ 比赛管理：项目工作台、成绩复核
├─ 比赛执行：现场任务、大屏
├─ 成绩：学校总分
├─ 系统维护：更正与导出、账号管理
└─ 个人：我的账号

项目工作台 8 页签：
计分任务 / 成绩复核 / 概况 / 报名 / 分组 / 赛程 / 比赛 / 成绩
（个人赛：计分任务 / 成绩复核 / 概况 / 报名 / 比赛 / 成绩）

不在侧栏的活路由：results、bracket、scoring、individual、review、matches 等
手机（≤900px）：侧栏折为横排滚动，390 下 10 项仅前 4—6 项可见
```

### 2.2 调整后（本批）

```text
侧栏（6 组 / 管理员 14 个入口）
├─ 赛事管理：赛事首页、赛事设置
├─ 项目与赛程：项目工作台、学校报名、分组与抽签、赛程与场地
├─ 比赛执行：现场任务、大屏
├─ 成绩：成绩与名次、学校总分、成绩复核、更正与导出
├─ 系统维护：账号管理
└─ 个人：我的账号

项目工作台 5 页签：
概况 / 报名 / 赛程（内部分组与抽签、比赛赛程、对阵图） / 比赛 / 成绩
（个人赛：概况 / 报名 / 成绩录入 / 成绩）

手机（≤620px）：菜单按钮 + 左侧分组抽屉（6 组完整保留）+ 底部 4 项快捷入口
平板/桌面（≥621px）：保持原侧栏/横排导航
```

### 2.3 入口与兼容映射

| 旧行为 | 新行为 |
| --- | --- |
| `tab=tasks` | 规范为 `tab=overview`，高亮“概况” |
| `tab=groups` / `tab=schedule&view=groups` | 规范为 `tab=schedule&view=groups`，赛程内“分组与抽签”视图 |
| `tab=review`（工作台页签） | 跳转侧栏 `#/resultReview`，按当前项目预选 |
| 个人赛 `tab=matches` 文案“比赛” | 页签文案“成绩录入”，`entry` 参数不变 |
| 侧栏 6 组横排滚动 | ≤620px 抽屉+底栏；834/1440 不变 |
| 隐藏 `#/results`、`#/bracket` | results 有侧栏入口；bracket 仍从赛程“对阵图”进入 |
